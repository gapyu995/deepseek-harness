# @deepseek-ai/dsh-client-ui-pet

[English](README.md) | 中文

Web 桌宠特性的归属方：向 [`dsh-client-ui-layout`](../ui-layout/README.md) 声明的框架级 `shell.overlay` 席位贡献一个条目（`id: 'pet'`）——一只可拖拽的艾莲吉祥物，悬浮在所有列之上、各滚动容器之外。悬浮层本身点击穿透、只对自身条目恢复指针事件，因此桌宠可拖拽、其控件可点击，却永远不会挡住底下的应用。

角色纯装饰。位置、拖拽手势与显隐都活在组件局部状态里：不写入任何 store，刷新即重置，也不读取任何会话、消息或工具状态。角色图是静态 shell 资产，由 `/ailian.png` 提供；悬停出现的关闭控件可在本次会话内隐藏它，角落的「桌宠」恢复药丸可再唤回。待机动画走共享的 `--ds-*` 动效 token，并尊重 `prefers-reduced-motion`。样式只用 token；文案走本包自己的 `pet` locale 命名空间。

## 模型体验

无，因为桌宠是纯装饰的浏览器侧悬浮层，不读取任何会话、消息或工具状态，也不注册任何面向模型的内容。

#### KV Cache effect

无；本包从不组装或发送 provider 请求。

## 已知限制与暂缓事项

- **状态是会话级** —— 位置与显隐都是组件局部状态，刷新即重置；目前还没有任何设置把它们持久化。
- **角色图是固定 shell 资产** —— 角色由 `apps/web/public/ailian.png` 提供而非包内资产，因此悬浮层按 URL 引用它，其他 shell 需要自行提供同名副本。
